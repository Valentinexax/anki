# Cloze Grammar: Japanese

Rebuild of the Anki "Cloze Grammar::Japanese" deck (Typecloze note type, 13-column TSV).
Chapter decks are now named in Japanese; the level outside the JLPT lists is
「番外（JLPT範囲外）」, which sorts after the N levels because Anki puts kanji after Latin.
The N levels keep their standard names, so Anki still lists N1 first and N5 last.
The root decks ("Cloze Grammar::Japanese") stay in English so they sit with the other languages.

- `original.txt`: the export as received (971 notes).
- `japanese_grammar_cloze.txt`: the rebuilt deck to import (979 notes). **Generated; don't edit by hand.**
- `CHANGES.md`: every Text/Translation change and the new cards (generated by `changes.py`).
- `move_to_new_decks.py`: Debug Console script for updating an existing collection.

## Pipeline

```sh
python3 parse.py        # original.txt -> work/original.json
python3 structure.py    # chapter plan, new cards, new sort IDs -> work/structure.json
python3 validate.py     # checks work/content/*.json (per-card notes, tip, register, compare, fixes)
python3 build.py        # applies OVERRIDES, writes the TSV, runs final checks
python3 changes.py      # writes CHANGES.md
```

`dupscan.py` (used by `validate.py` and `build.py`) flags sentence pairs with word-set
Jaccard >= 0.55, or >= 0.35 together with a difflib ratio > 0.8. Japanese has no spaces, so
words come from the MeCab tokeniser (`fugashi` + `unidic-lite`, in `requirements.txt`);
particles and auxiliaries count as words. The answer-in-hint check matches Japanese answers
as substrings, since whole-word matching doesn't work without spaces.

## Importing into Anki

**New collection (no old Japanese deck):** File → Import → `japanese_grammar_cloze.txt`. Done.

**Updating the old deck** (GUIDs match, so review history carries over):

1. File → Import → `japanese_grammar_cloze.txt`, note type *Typecloze*, update existing notes.
   All old notes already use Typecloze, so nothing needs converting first.
2. Tools → Debug Console, paste `move_to_new_decks.py`, press Ctrl+Enter: Anki updates notes
   but leaves cards in their old decks, so this moves each card to the chapter its Sort ID
   belongs to and removes the old English-named chapter decks once empty.
3. Tools → **Empty Cards** → delete. Notes that used to have c2/c3 keep those extra cards as
   empty cards until you do; the c1 card keeps its own history.

Tested on a scratch collection built from `original.txt`: fresh import 979 new, 0 conflicting;
update 971 updated + 8 new, 0 conflicting; 1,036 cards moved, 61 empty decks removed; 65 empty
cards deleted, leaving 979 notes / 979 cards in 56 decks; a reviewed card kept its interval.
