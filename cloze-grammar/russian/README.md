# Cloze Grammar: Russian

Rebuild of the Anki "Cloze Grammar::Russian" deck (Typecloze note type, 13-column TSV).
Chapter decks are now named in Russian; the level above C2 is «Дополнительно (выше C2)»,
which sorts after C2 because Anki puts Cyrillic after Latin.

- `original.txt`: the export as received (1,059 notes).
- `russian_grammar_cloze.txt`: the rebuilt deck to import (1,069 notes). **Generated; don't edit by hand.**
- `CHANGES.md`: every Text/Translation change and the new cards (generated by `changes.py`).
- `convert_connectors.py`, `move_to_new_decks.py`: Debug Console scripts for updating an existing collection.

## Pipeline

```sh
python3 parse.py        # original.txt -> work/original.json
python3 structure.py    # chapter plan, new cards, new sort IDs -> work/structure.json
python3 validate.py     # checks work/content/*.json (per-card notes, tip, register, compare, fixes)
python3 build.py        # applies OVERRIDES, writes the TSV, runs final checks
python3 changes.py      # writes CHANGES.md
```

`dupscan.py` (used by `validate.py` and `build.py`) flags sentence pairs with word-set
Jaccard >= 0.55, or >= 0.35 together with a difflib ratio > 0.8. Words are whole Cyrillic
word forms, so different case forms of one word count as different words.

## Importing into Anki

**New collection (no old Russian deck):** File → Import → `russian_grammar_cloze.txt`. Done.

**Updating the old deck** (GUIDs match, so review history carries over):

1. **Before importing**, open Tools → Debug Console, paste `convert_connectors.py`, press
   Ctrl+Enter. The old deck's 335 Supplement notes use a note type called *connectors*; the new
   file puts every note on *Typecloze*, and Anki silently skips ("conflicting") any note whose
   type differs. The script converts them and keeps their IDs, GUIDs and reviews. Anki will ask
   for a one-way full sync afterwards.
2. File → Import → `russian_grammar_cloze.txt`, note type *Typecloze*, update existing notes.
3. Debug Console again with `move_to_new_decks.py`: Anki updates notes but leaves cards in their
   old decks, so this moves each card to the chapter its Sort ID belongs to and removes the old
   English-named chapter decks once empty.
4. Tools → **Empty Cards** → delete. The notes that used to have c2/c3 keep those extra cards as
   empty cards until you do; the c1 card keeps its own history.

Tested on a scratch collection built from `original.txt` (with a *connectors* copy of
Typecloze): 335 notes converted; 1,059 updated + 10 new, 0 conflicting; 1,135 cards moved,
66 empty decks removed; 76 empty cards deleted, leaving 1,069 notes / 1,069 cards in 68 decks.
