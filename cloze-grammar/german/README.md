# Cloze Grammar: German

Rebuild of the Anki "Cloze Grammar::German" deck (Typecloze note type, 13-column TSV).
Chapter decks are now named in German; the level above C2 is "Zusatz (über C2)", which
sorts after C2 alphabetically. The root decks ("Cloze Grammar::German") stay in English so
they sit with the other languages.

- `original.txt`: the export as received (855 notes).
- `german_grammar_cloze.txt`: the rebuilt deck to import (859 notes). **Generated; don't edit by hand.**
- `CHANGES.md`: every Text/Translation change and the new cards (generated by `changes.py`).
- `move_to_new_decks.py`: Debug Console script for updating an existing collection.

## Pipeline

```sh
python3 parse.py        # original.txt -> work/original.json
python3 structure.py    # chapter plan, new cards, new sort IDs -> work/structure.json
python3 validate.py     # checks work/content/*.json (per-card notes, tip, register, compare, fixes)
python3 build.py        # applies OVERRIDES, writes the TSV, runs final checks
python3 changes.py      # writes CHANGES.md
```

`dupscan.py` (used by `validate.py` and `build.py`) flags sentence pairs with word-set
Jaccard >= 0.55, or >= 0.35 together with a difflib ratio > 0.8.

## Importing into Anki

**New collection (no old German deck):** File → Import → `german_grammar_cloze.txt`. Done.

**Updating the old deck** (GUIDs match, so review history carries over):

1. File → Import → `german_grammar_cloze.txt`, note type *Typecloze*, update existing notes.
   All old notes already use Typecloze, so nothing needs converting first.
2. Tools → Debug Console, paste `move_to_new_decks.py`, press Ctrl+Enter: Anki updates notes
   but leaves cards in their old decks, so this moves each card to the chapter its Sort ID
   belongs to and removes the old English-named chapter decks once empty.
3. Tools → **Empty Cards** → delete. Notes that used to have c2/c3 keep those extra cards as
   empty cards until you do; the c1 card keeps its own history.

Tested on a scratch collection built from `original.txt`: fresh import 859 new, 0 conflicting;
update 855 updated + 4 new, 0 conflicting; 931 cards moved, 87 empty decks removed; 79 empty
cards deleted, leaving 859 notes / 859 cards in 88 decks; a reviewed card kept its interval.
